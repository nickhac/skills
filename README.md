# Skills

Agent skills for fundraising, go-to-market, startup judgment, and long agent loops.

Each folder is one skill. Open `SKILL.md` for the instructions.

## Fundraising and GTM

| Skill | What it does |
| --- | --- |
| [vc-pitch-deck-architect](vc-pitch-deck-architect/SKILL.md) | Turn a deck, site, one-pager, or demo into a seed or Series A narrative. |
| [vc-cold-email](vc-cold-email/SKILL.md) | Turn fundraising material into investor teasers and cold emails that ask for advice. |
| [vc-icp](vc-icp/SKILL.md) | Define ICPs, partner profiles, community profiles, anti-ICPs, and buying triggers. |
| [vc-positioning](vc-positioning/SKILL.md) | Define, validate, and activate product positioning for fundraising, sales, and GTM. |

`vc-pitch-deck-architect` also includes [slide-framework.md](vc-pitch-deck-architect/slide-framework.md).

## Paul Graham

Startup judgment skills, grouped under [paul-graham](paul-graham/).

| Skill | What it does |
| --- | --- |
| [pg-pressure-test](paul-graham/pg-pressure-test/SKILL.md) | Find fatal flaws in an idea before you build it. |
| [pg-validate-real-problem](paul-graham/pg-validate-real-problem/SKILL.md) | Check whether people will pay, and write the discovery questions. |
| [pg-map-competitor](paul-graham/pg-map-competitor/SKILL.md) | Map real competitors, including what people do today instead. |
| [pg-build-something-people-want](paul-graham/pg-build-something-people-want/SKILL.md) | Cut the product to the smallest two-week test of one assumption. |
| [pg-find-first-10-customers](paul-graham/pg-find-first-10-customers/SKILL.md) | Plan the unscalable work that gets the first ten customers. |
